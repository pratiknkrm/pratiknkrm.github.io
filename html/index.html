Featured Project

Zero-Trust Secrets Management Infrastructure

A self-hosted, zero-knowledge enterprise password management environment routed through a strictly authenticated zero-trust network access (ZTNA) mesh.

01

Zero-Trust Network Access (ZTNA)

  • Bypassed traditional NAT and port-forwarding vulnerabilities by routing all traffic through a private Tailscale VPN mesh.
  • Enforced strict identity access controls by modifying environment variables to lock vault registration exclusively to the master administrator.
02

Cryptographic Security

  • Satisfied modern Web Crypto API requirements by implementing automated Let's Encrypt SSL certificates tied to Tailscale MagicDNS.
  • Resolved severe IPv4/IPv6 cryptographic handshake conflicts by mapping TLS backends directly to explicit loopback addresses.
03

Containerized Architecture

  • Deployed Vaultwarden and SQLite via an unprivileged Proxmox Debian LXC container for strict resource isolation.
  • Engineered secure network routing by passing the hypervisor's /dev/net/tun device directly through to the container OS.
